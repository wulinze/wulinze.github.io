寻找重复数

发表于 2025-10-28 分类于 LeetCode 刷题
记录二分计数、二进制标记与快慢指针判环三种寻找重复数的思路。

之前有异或求解的，不过这道题不太一样。

问题描述：给定一个包含 n + 1 个整数的数组 nums，其数字都在 1 到 n 之间（包括 1 和 n），可知至少存在一个重复的整数。假设只有一个重复的整数，找出这个重复的数。

  • 方法一：单调性求解(二分查找)(O(nlogn))

可以对于数组进行遍历求解，可知其中一个特性，设cnt[i]代表所有$\leq$i的数的数量如果不重复则必定有cnt[i]≤icnt[i]\leq icnt[i]≤i若有重复则满足cnt[i]>icnt[i]>icnt[i]>i

  • 方法二：标记求解(二进制)(O(nlogn))
  • Floyd 判圈法（快慢指针，O(n)O(n)O(n)）

把数组下标看作节点，i → nums[i] 看作有向边。从下标 0 出发会进入一个环，环入口对应重复数字。先让慢指针每次走一步、快指针每次走两步，找到两者的相遇点。

设起点到环入口的距离为 aaa，环长为 LLL，相遇点距入口沿环方向的距离为 bbb。相遇时两指针路程差是环长的整数倍，因此 a+b≡0(modL)a+b\equiv 0\pmod La+b≡0(modL)。将一个指针重置到下标 0，另一个留在相遇点，之后都每次走一步；走过 aaa 步时两者会在环入口相遇，返回该节点即可。
